What the API did

  1. POST /checkout — expire_stale(), lock variants in id order, reserved += qty, Razorpay order, orders.pending_payment
  2. Razorpay modal → POST /checkout/{id}/verify — HMAC check → mark_paid(): paid, stock −= qty, reserved −= qty
  3. Webhook payment.captured a few seconds later → same mark_paid() → no-op; event id stored
  4. POST /orders/OC-1042/claim { password } → user created, order + address attached
